# Kaggle

A collection of Kaggle exercises, data science projects, and personal research work focused on machine learning and data analysis.

## 📁 Directory Structure

### `/exercises`
Jupyter notebook exercises covering fundamental data science concepts:

- **exercise-introduction.ipynb** - Introduction to data science fundamentals
- **exercise-missing-values.ipynb** - Techniques for handling missing data
- **exercise-categorical-variables.ipynb** - Methods for working with categorical variables

### `/melbourne-housing`
A comprehensive machine learning project analyzing Melbourne housing data with predictive modeling:

- **data.csv** - Melbourne housing dataset
- **load_data.py** - Data loading and preprocessing utilities
- **decision.tree.py** - Decision tree model implementation
- **model.validation.py** - Model validation techniques and metrics
- **validation.from.unseen.data.py** - Testing model performance on unseen data

### `/personal_research`
Advanced research notebooks exploring specialized machine learning topics:

- **undestanding_regression.ipynb** - In-depth exploration of regression models and techniques
- **understanding_preprocessing_pipelines.ipynb** - Data preprocessing and pipeline construction
- **flights.csv** - Flight dataset for analysis
- **DateTimeEncoder/** - Custom datetime encoding implementation

## 🎯 Topics Covered

- Data preprocessing and cleaning
- Handling missing values
- Categorical variable encoding
- Decision tree modeling
- Regression analysis
- Model validation and evaluation
- Data preprocessing pipelines

## 💻 Technologies
